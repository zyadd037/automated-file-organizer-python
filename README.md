# Automated File Organizer

A Python project that automatically organizes files into separate folders based on their file extensions.

## Features
- Automatically sorts files into categories such as Images, Documents, Videos, Music, Archives, and Programming.
- Supports a Preview Mode to check file organization before moving files.
- Creates category folders automatically.
- Prevents overwriting files by generating unique filenames.
- Displays a summary of organized, failed, and skipped files.

## Technologies Used
- Python
- os module
- shutil module

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python Automated_file_organizer.py
```

5. Enter the directory path you want to organize.
6. Choose `Yes` for Preview Mode or `No` to organize the files.

## Note
It is recommended to test the program on a separate folder containing sample files before organizing important files.
